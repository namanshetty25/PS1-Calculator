# PS1-Calculator

Welcome to **PS1-Calculator**!

This project is my very first coding project, developed to strengthen my programming skills and understanding of C++. The calculator is a basic console application written entirely in C++ that performs simple arithmetic operations.

## Features

- Addition, subtraction, multiplication, and division
- User-friendly console interface
- Written in pure C++

## Getting Started

### Prerequisites

- A C++ compiler (such as g++, clang)
- Basic knowledge of command-line operations

### Compilation

To compile the calculator, navigate to the project directory and run:

```bash
g++ -o calculator main.cpp
```

Replace `main.cpp` with the main source file if it differs.

### Usage

Run the executable:

```bash
./calculator
```

Follow the on-screen instructions to perform calculations.
